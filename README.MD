# Sales Data Analysis

A data analysis project focused on analyzing sales data to identify useful insights, trends, and patterns.

## Features

- Analyze sales data
- Calculate total sales
- Analyze sales by product
- Compare sales performance
- Identify top-performing products
- Analyze sales trends
- Visualize data using charts

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## Dataset

The project uses sales data containing information such as products, sales amounts, quantities, and other sales-related details.

## Purpose

This project was created to practice data cleaning, data analysis, and data visualization using Python.

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:
